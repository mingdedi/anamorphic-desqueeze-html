# 🎬 1.33x 变形宽银幕反挤压工具

一个纯前端、无服务端的变形宽银幕（Anamorphic）镜头照片反挤压处理工具。支持单张处理和批量文件夹处理，所有计算均在浏览器本地完成，无需上传图片到服务器。

## 功能特性

- **1.33x 横向反挤压** — 将变形宽银幕镜头拍摄的横向压缩照片还原至正常比例
- **1.33x 竖向反挤压** — 支持竖向压缩的还原
- **单张 / 批量模式** — 支持单个文件处理或整个文件夹批量处理
- **自动跳过** — 已处理过的文件（文件名含 `_desqueezed` 标记）会自动跳过，避免重复处理
- **拖拽上传** — 桌面端支持拖拽图片到区域上传
- **全部下载 / 单张下载** — 处理完成后可下载全部结果或单张保存
- **本地隐私安全** — 所有处理在浏览器内通过 Canvas 完成，图片不上传任何服务器

## 使用方式

1. 用浏览器直接打开 `index.html`
2. 选择输入模式（单张 / 文件夹）
3. 选择反挤压方向（横向 / 竖向）
4. 点击区域选择图片或将图片拖拽到区域
5. 点击「开始处理」
6. 处理完成后下载结果

## 支持的图片格式

JPG / PNG / WebP / HEIC

## 技术说明

- 纯 HTML + CSS + JavaScript，零依赖
- 基于 Canvas API 进行图片缩放计算
- 命名规则：`原文件名_desqueezed.扩展名`
